# Hometown Hub

Digital community platform for a village/neighbourhood (HTML, Tailwind CSS, vanilla JavaScript).

## Structure
- `index.html` – markup
- `css/styles.css` – custom styles
- `js/tailwind.config.js` – Tailwind CDN config
- `js/app.js` – application logic

## Run
Open `index.html` in a browser (internet needed for Tailwind CDN and Google Fonts).
